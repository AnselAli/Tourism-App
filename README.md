## 📱 About The Project

**ExploreTT** is a mobile application built with **Expo + React Native** designed to help users explore locations, culture, and attractions across Trinidad & Tobago.

Whether you're a **tourist** or a **local adventurer**, ExploreTT helps you discover places worth visiting.

✨ Features include:
- 📍 Location discovery  
- 🗺 Interactive exploration  
- 📸 Cultural highlights  
- 🌴 Travel inspiration
